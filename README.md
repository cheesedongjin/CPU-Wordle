# CPU WORDLE

CPU WORDLE은 한글과 영어 단어를 맞히는 웹 게임입니다. 단어를 입력하면 각 글자를 정답과 비교해 색깔로 표시하고, 사용자는 이 힌트를 보고 다음 단어를 추측합니다. 기본·해커·탐정 모드를 제공하며, 문제 코드를 공유하면 친구도 같은 문제를 풀 수 있습니다.

게임 규칙은 **C**, 화면과 입력 처리는 **HTML·CSS·JavaScript**로 만들었습니다. C 코드는 브라우저에서 실행할 수 있는 **WebAssembly** 형태로 변환해 사용합니다. 게임 계산과 단어 검색은 사용자의 브라우저 안에서 이루어집니다.

## 1. 제작 내용

단어를 입력하고 결과를 확인하는 게임 흐름에 다음 기능을 구현했습니다.

- **한글·영어 지원:** 한글은 자음과 모음으로 나누고, 영어는 알파벳 단위로 비교합니다.
- **정답 판정:** 글자의 위치와 개수를 함께 확인해 초록·노랑·회색 힌트를 만듭니다.
- **세 가지 모드:** 단어 하나를 맞히는 기본 모드, 일부 힌트를 숨기는 해커 모드, 두 이름을 찾는 탐정 모드를 제공합니다.
- **입력 안내:** 입력 중인 단어가 몇 칸으로 나뉘는지 보여 주고, 칸 수와 단어 목록을 확인합니다.
- **사용한 글자 표시:** 지금까지 얻은 글자별 힌트를 키보드 모양으로 모아 보여 줍니다.
- **문제 공유:** 문제 코드로 같은 모드·언어·정답의 문제를 다시 열 수 있습니다.
- **모드별 화면:** 선택한 모드에 따라 색상, 안내 문구, 보드 구성이 바뀝니다.

## 2. 실행 방법

### GitHub 저장소 접속

[CPU-Wordle GitHub 저장소](https://github.com/cheesedongjin/CPU-Wordle)에서도 프로젝트에 접속할 수 있습니다. 소스 코드와 사용 안내를 확인하거나, **Code → Download ZIP**으로 프로젝트를 내려받아 아래 방법으로 게임을 실행할 수 있습니다.

### 파일을 직접 열기

1. 저장소를 내려받습니다. ZIP으로 받았다면 먼저 압축을 풉니다.
2. 프로젝트 폴더 안의 `web/index.html`을 브라우저로 엽니다.
3. 처음에는 기본 모드의 한글 5칸 문제가 시작됩니다.

WebAssembly를 지원하는 브라우저를 사용합니다. 실행에 필요한 단어 데이터와 변환된 C 코드가 저장소에 포함되어 있으므로, **게임을 실행하기 위해 C 컴파일러나 Node.js를 설치할 필요는 없습니다.** `web` 폴더의 파일들은 함께 유지합니다.

### 로컬 웹 서버로 열기

Python이 설치되어 있다면 프로젝트 최상위 폴더에서 다음 명령으로도 실행할 수 있습니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

서버를 실행한 상태에서 브라우저로 [http://127.0.0.1:8000/web/](http://127.0.0.1:8000/web/)에 접속합니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다. 이 서버는 브라우저에 파일을 전달하는 역할이며, 게임 규칙은 그대로 브라우저에서 계산합니다.

## 3. 사용 방법

1. 화면 위쪽에서 **기본·해커·탐정** 중 모드를 선택합니다.
2. 설정에서 **한글·영어**와 **단어 길이**를 선택합니다. 탐정 모드는 5칸 고정입니다.
3. 입력란에 완성된 단어를 적습니다. 입력란 아래에서 글자가 나뉜 모습과 칸 수를 확인할 수 있습니다.
4. **입력** 버튼이나 `Enter`를 누릅니다. 탐정 모드에서는 화면에 표시된 이름 후보 중 하나를 입력합니다.
5. 게임판의 색깔과 사용한 글자 표시를 참고해 다음 단어를 추측합니다.
6. 정답을 모두 맞히거나 기회를 다 쓰면 게임이 끝나고 결과와 정답이 표시됩니다.

**다른 문제** 버튼은 같은 설정으로 문제를 다시 뽑습니다. 모드·언어·길이를 바꾸거나 다른 문제 코드를 열면 새 게임이 시작됩니다. 진행 기록은 현재 열린 화면에서 유지되며, 새로고침하면 새 게임으로 시작합니다. 화면 위쪽의 **?** 버튼으로 게임 방법을 다시 볼 수 있습니다.

## 4. 게임 규칙

### 색깔 판정

| 표시 | 뜻 |
|---|---|
| 초록 | 글자와 위치가 모두 맞습니다. |
| 노랑 | 정답에 있는 글자이지만 위치가 다릅니다. |
| 짙은 회색 | 정답에 없거나, 같은 글자의 개수를 초과한 입력입니다. |
| 줄무늬 | 해커 모드에서 해당 칸의 판정이 숨겨졌습니다. |

같은 글자를 여러 번 입력하면 **정답에 들어 있는 개수만큼만** 초록이나 노랑으로 표시합니다. 위치까지 맞는 글자를 먼저 확인하고, 남은 정답 글자와 나머지 입력을 비교합니다.

예를 들어 정답이 `apple`이고 입력이 `allee`이면 결과는 **초록·노랑·회색·회색·초록**입니다. 정답의 `l`은 하나이므로 첫 `l`만 노랑입니다. 마지막 `e`는 위치까지 맞아 초록이고, 앞의 `e`는 회색입니다.

### 한글의 칸 수

한글은 완성된 글자 수가 아니라 자음·모음으로 나눈 칸 수를 사용합니다.

- `사과` → `ㅅ ㅏ ㄱ ㅗ ㅏ` → **5칸**
- `ㅘ`는 `ㅗ + ㅏ`, 겹받침 `ㄳ`은 `ㄱ + ㅅ`으로 나눕니다.
- `ㅐ`와 쌍자음은 한 칸으로 처리합니다.

사용자는 자모를 따로 입력하지 않고 `사과`처럼 완성된 단어를 입력하면 됩니다. 칸 수가 맞지 않거나 단어 목록에 없는 입력은 안내 문구를 보여 주고 기회를 차감하지 않습니다.

### 모드별 동작

| 모드 | 기회 | 목표 |
|---|---|---|
| 기본 | 6번 | 단어 하나 맞히기 |
| 해커 | 7번 | 일부 힌트가 가려진 상태에서 단어 하나 맞히기 |
| 탐정 | 공통 7번 | 이름 두 개 모두 맞히기 |

**기본 모드:** 한글·영어와 5~7칸 중 길이를 선택하고, 색깔 힌트로 정답을 좁혀 갑니다.

**해커 모드:** 기본 모드와 같은 방식으로 단어를 비교한 뒤, 오답인 줄에서 무작위 한 칸의 판정 색을 숨깁니다. 해당 칸은 입력한 글자만 보이고 줄무늬로 표시됩니다. 정답을 입력한 줄은 모든 칸을 초록으로 보여 줍니다.

**탐정 모드:** 언어별 이름 후보 100개 중 서로 다른 두 이름을 찾습니다. 한 번 입력하면 A와 B의 정답을 각각 비교합니다. 두 이름은 서로 다른 차례에 맞혀도 되며, 둘 다 맞히면 승리합니다. 사용한 글자 키보드는 인물별 보드 아래에 따로 표시합니다. 한 인물을 맞힌 뒤에는 그 인물의 보드와 키보드가 맞힌 시점의 기록을 유지하므로 남은 인물에 집중할 수 있습니다.

## 5. 문제 코드 공유

1. **문제 코드 공유**를 펼칩니다.
2. 현재 문제 코드 옆의 **복사**를 눌러 친구에게 전달합니다.
3. 친구는 **친구의 문제 코드** 입력란에 붙여 넣고 **열기**를 누릅니다.
4. 같은 모드·언어·길이·정답으로 문제가 시작됩니다.

자동 복사가 지원되지 않는 환경에서는 코드가 선택되며, `Ctrl+C` 또는 기기의 복사 기능으로 복사할 수 있습니다.

| 모드 | 코드 형식 |
|---|---|
| 기본 | `CW2-언어-단어ID` |
| 해커 | `CWH2-언어-단어ID` |
| 탐정 | `CWD2-언어-이름ID-이름ID` |

예를 들어 `CW2-EN-F123CC0B`는 기본 모드의 영어 정답 `apple`을 가리킵니다. 단어 ID는 단어 자체를 정해진 계산으로 숫자로 바꾼 값입니다. 이런 계산을 **해시**라고 합니다. 같은 코드 버전에서는 단어 목록의 정렬 순서와 관계없이 같은 정답을 찾을 수 있습니다.

문제 코드를 받은 사람은 각자의 화면에서 문제를 풀 수 있습니다. 해커 모드의 가림 위치는 플레이마다 달라질 수 있습니다. 다른 버전에서 해당 단어가 출제 목록에서 빠진 경우에는 그 코드를 열 수 없습니다.

## 6. 프로그램의 동작 과정

### 새 문제 시작

선택한 언어와 길이에 맞는 출제 목록에서 단어를 무작위로 뽑습니다. 탐정 모드에서는 이름 후보에서 서로 다른 두 이름을 뽑습니다. 선택한 문제에 맞춰 보드, 남은 기회, 입력란, 문제 코드를 준비합니다.

### 단어 입력부터 결과 표시까지

1. **입력 정리:** 앞뒤 공백을 지우고 영어 대문자를 소문자로 바꿉니다. 한글을 조합하는 중에는 제출하지 않습니다.
2. **글자 분해와 확인:** 단어를 한글 자모 또는 영어 알파벳으로 나누고, 칸 수와 단어 목록을 확인합니다.
3. **정답 비교:** C 코드가 위치까지 맞는 글자를 먼저 찾고, 남은 글자에서 위치만 다른 글자를 찾습니다.
4. **모드 규칙 적용:** 해커 모드는 오답의 한 칸을 가리고, 탐정 모드는 두 정답의 판정과 성공 여부를 각각 기록합니다.
5. **승패 결정:** 정답을 모두 맞혔는지, 기회를 다 썼는지 확인합니다.
6. **화면 갱신:** 입력한 단어와 판정 색을 게임판에 표시하고, 키보드 힌트와 진행 횟수를 바꿉니다. 게임이 끝나면 결과를 표시합니다.

### 주요 구현 방식

- **중복 글자 처리:** 정답의 각 칸을 이미 사용했는지 기록합니다. 정답 글자 하나를 여러 입력 칸에 중복으로 인정하지 않도록 합니다.
- **한글 분해:** 컴퓨터에 저장된 한글 번호의 규칙을 이용해 첫 자음·모음·받침을 찾습니다. 이를 게임에서 비교할 칸 목록으로 바꿉니다.
- **탐정 모드의 성공 기록:** 이미 맞힌 이름을 계속 기억해 두 이름을 서로 다른 차례에 맞힐 수 있도록 합니다.
- **키보드 힌트:** 글자마다 지금까지 받은 가장 좋은 판정을 남깁니다. 한 번 초록으로 확인한 글자는 이후 입력에서 다른 판정을 받아도 초록 정보를 유지합니다.

## 8. 개발과 확인 방법

코드를 수정하거나 테스트할 때는 **Node.js 22, Python 3, Zig 0.17.1**을 사용합니다. Zig에 포함된 clang으로 C 코드를 컴파일합니다. 아래 명령은 프로젝트 최상위 폴더에서 실행합니다.

```sh
pip install ziglang==0.17.1
python scripts/test_c.py
python scripts/build_wasm.py
python scripts/bundle_data.py
node --test tests/test_local.cjs
python scripts/build_pages.py
```

- `test_c.py`: C의 게임 규칙을 직접 실행해 확인합니다.
- `build_wasm.py`: 수정한 C를 `web/wordle_wasm.js`로 변환합니다. C를 수정했다면 브라우저에 반영하기 위해 이 과정을 실행합니다.
- `bundle_data.py`: 단어 목록을 `web/words.js`로 묶습니다.
- `test_local.cjs`: C와 JavaScript의 연결 및 화면 흐름을 확인합니다.
- `build_pages.py`: 배포할 파일을 `build/pages`에 모으고 파일 연결을 확인합니다.

자동 검사와 배포 순서는 [.github/workflows/ci.yml](.github/workflows/ci.yml)에 있습니다. C·JavaScript 테스트와 생성 파일 확인을 통과하면 `main` 브랜치의 결과를 GitHub Pages에 배포합니다. 다른 정적 호스팅에도 `build/pages` 폴더를 올릴 수 있습니다.
