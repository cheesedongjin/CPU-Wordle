# CPU WORDLE

한글·영어 워들을 브라우저에서 혼자 풀고, 문제 코드를 친구에게 공유하는 작은 게임입니다.

## 실행

`web/index.html`을 브라우저에서 열면 됩니다. 설치, 빌드, 계정, API 서버, 데이터베이스가 필요 없습니다. 인터넷 연결 없이도 게임이 동작합니다.

1. 언어와 길이를 선택하고 **새 문제**를 누릅니다.
2. **문제 코드 복사**를 눌러 친구에게 보냅니다.
3. 친구가 **친구의 문제 코드**에 붙여 넣고 **이 코드로 풀기**를 누르면 같은 문제가 열립니다.

기본 모드는 6번의 기회입니다. 해커 모드는 7번이며 오답마다 무작위 한 칸의 글자와 판정이 가려지고, 정답은 모든 칸이 공개됩니다. 탐정 모드는 한글 자모·영어 알파벳 5칸 고정으로, 언어별 이름 후보 100개에서 서로 다른 두 이름을 공통 7번의 기회 안에 찾습니다. 한 번 입력하면 두 보드에 동시에 판정되며, 키보드의 인물을 선택해 각 단서를 확인할 수 있습니다. 모드는 화면 위쪽의 큰 메뉴에서 고르며, 모드에 따라 페이지 전체 테마가 바뀝니다. 모드·언어·길이를 바꾸면 바로 새 문제가 시작되고, **다른 문제** 버튼은 같은 설정으로 새 문제를 뽑습니다. 한글은 자모 5~12칸, 영어는 5~8칸입니다. 잘못된 입력은 기회를 사용하지 않습니다. 설정을 바꾸거나 다른 코드를 열면 현재 진행이 초기화되며, 새로고침하면 진행 내용은 사라집니다.

## 구성

- `web/index.html`, `styles.css`, `app.js`: 화면과 게임 흐름
- `web/engine.js`: 자모 분해, 중복 글자 판정, 안정적인 문제 코드
- `web/words.js`: 로컬 사전 번들. 원본 변경 후 `python scripts/bundle_data.py`로 재생성
- [데이터 출처와 라이선스](data/README.md)

정적 호스팅에는 `web/`과 `data/`를 같은 상위 경로에 올리고 `web/index.html`로 접속하면 됩니다. 이 변경은 기존 호스팅에 자동 배포하지 않습니다.

## 검증

```sh
python scripts/bundle_data.py
node --test tests/test_local.cjs
node --check web/app.js
```

문제 코드는 `CW1-언어-단어ID` 형식입니다. 사전 순서나 선택한 길이와 관계없이 같은 코드는 같은 정답을 가리킵니다. 다른 버전에서 삭제된 단어의 코드는 유효하지 않은 코드로 표시됩니다. 정답과 사전은 브라우저에 포함되므로 친구끼리 가볍게 즐기는 용도입니다.

테마 공유 코드: 해커는 `CWH1-언어-단어ID`, 탐정은 `CWD1-언어-이름ID-이름ID`입니다. 기존 `CW1` 코드는 기본 모드로 열립니다. 해커의 가림 위치는 각 플레이에서 무작위로 정해집니다. 탐정 이름 목록은 게임용 후보이며 일반 단어 사전과 별도로 관리합니다.
