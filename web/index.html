게임 방법

6번 안에 정답을 찾아보세요. 모든 모드에서 초록은 글자와 위치 일치, 노랑은 다른 위치에 포함된 글자, 짙은 회색은 남아 있는 같은 글자가 없음을 뜻합니다. 아직 입력하지 않은 글자와 판정 전의 칸은 회색입니다.

해커: 7번의 기회이며 오답을 입력하면 무작위 한 칸의 판정이 가려져 줄무늬 칸으로 표시되고, 입력한 글자만 보입니다. 정답을 입력하면 가려짐 없이 모든 칸이 초록으로 공개됩니다. 탐정: 한글 자모·영어 알파벳 5칸 고정이며 언어별 후보 100개 중 두 이름을 공통 7번의 기회 안에 찾아보세요. 이름 하나를 제출하면 두 보드에 동시에 단서가 표시됩니다. 찾은 이름은 계속 확인 상태로 남습니다.

한글은 자모로 나눕니다. 사과 → ㅅ ㅏ ㄱ ㅗ ㅏ (5칸). ㅘ와 겹받침은 나누고, ㅐ와 쌍자음은 한 칸입니다.
